# FlowForge — Local Flow Assistant

A local-first Chrome Manifest V3 prompt workspace.

## Principles
- No account, login, subscription, checkout, payment, trial, plan, entitlement endpoint, telemetry, or extension-imposed prompt quota.
- Prompt queue stored locally with `chrome.storage.local`.
- Import and export prompts as JSON.
- Open Google Flow in a browser tab and copy prompts manually.

## Scope
This local queue is unlimited by FlowForge. It does not unlock paid Google Flow features or remove Google's own generation quotas, account restrictions, rate limits, or service availability constraints.

This is the initial architecture note, not a completed generation automation implementation.
